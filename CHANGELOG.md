# Changelog (one line per step, newest last)

- Stage 1 (v0.1.0): UI foundation. Navigable Compose app, design system, 10 guide overlays, in-memory presets, GitHub Actions build. Camera not connected.
- Stage 2 (v0.2.x): Real CameraX camera (photo, video, front/back, pinch zoom, tap focus, EV, flash/torch, timer, 3:4 / 9:16), Pro mode (manual ISO, shutter, focus, white balance where the phone supports it), live histogram, real gallery/review/share/delete, real device capabilities, saved settings (gridlines, shutter sound, volume-button shutter, haptics, restore defaults), in-app updater via GitHub Releases, personal signing key, redesigned camera UI. Builds 2-3 failed (a wrong import, then one outdated unit test), fixed in build 4. Still untested on a phone.
